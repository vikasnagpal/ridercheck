# RiderCheck / Partner Verification Dashboard

Interactive prototype of a PCC compliance platform and partner verification dashboard for gig-worker fleets.

## Live Prototype

- Live URL: [vikasnagpal.com/ridercheck/](https://vikasnagpal.com/ridercheck/)

## Overview

Self-contained design-component prototype featuring:
- Coverage metrics and SLA tracking
- Fleet verification and partner management
- Store-level ops console and audit tools
- Client theming (e.g. Zepto and neutral modes)
